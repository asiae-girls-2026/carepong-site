# 필리몽(Pillymon) 배포 랜딩 사이트 — 설계 문서

- **작성일**: 2026-06-20
- **작성자**: PM
- **상태**: 설계 승인 대기

## 1. 한 줄 정의

데스크탑 펫 건강 도우미 앱 **"필리몽(Pillymon)"**의 배포용 랜딩 사이트. 제품을
소개하고(건강+귀여움 균형) 다운로드로 유도한다. 1차에는 **다운로드 버튼은 자리만**
두고(실제 설치파일 연결은 이후), 소개 페이지를 제대로 만든다.

## 2. 목표 & 성격

- **배포 입구**: 추후 .dmg가 준비되면 다운로드를 연결할 랜딩.
- **제품 소개**: 복약·수분 알림 + 다마고치형 성장·친구·교배를 한 화면에서 전달.
- **포트폴리오 자산**: 헬스케어 도메인 전환을 보여줄 제품 사례.

## 3. 범위 (Scope)

### 1차 (이 문서의 대상)
- **단일 롱스크롤 랜딩 페이지** (접근 방식 A).
- 섹션: 히어로 / 기능 / 미리보기·성장 / 소개(스토리) / 푸터 CTA.
- **다운로드 버튼**: 스타일만, 실제 파일 연결 없음("곧 출시" 상태).
- 앱의 **스프라이트 PNG를 비주얼 에셋으로 재사용**(실제 앱 스크린샷 대신 스프라이트 기반 목업).

### 비범위 (이후)
- 실제 다운로드 파일(.dmg) 연결 — 패키징 완료 후.
- 이메일 수집/대기명단, 백엔드, 분석.
- 실제 앱 스크린샷, 다국어, 블로그/문서.

## 4. 기술 스택 & 배포

- **Next.js (App Router) + TypeScript + Tailwind CSS**.
- **Vercel 배포** (별도 프로젝트, 예: `pillymon.vercel.app`).
- 단일 페이지(`app/page.tsx`) + 섹션 컴포넌트. 서버 데이터 없음(정적).
- 폰트: Pretendard(한글) + 디스플레이용 1종. 무채색 + 레드(#e4002b) 포인트.

## 5. 브랜드 / 비주얼

- **이름**: 필리몽 (Pillymon) — Pill + mon, 다마고치 감성.
- **톤**: 무채색 베이스 + 레드 포인트(포폴 톤 통일), 둥근 카드, 귀여운 펫.
- **마스코트 비주얼**: 앱의 슬라이스 스프라이트(`desktop-pet/src/renderer/assets/pets/`)에서
  대표 몇 종(예: 고양이/강아지/교배종)을 `public/`으로 복사해 사용. 히어로의 펫은
  CSS로 살짝 까딱(bob/blink) 정도의 모션.

## 6. 페이지 구성 (섹션)

1. **히어로**
   - 제품명 "필리몽", 한 줄 태그라인(예: "복약·수분, 필리몽이 챙겨줄게요. 키우는 재미는 덤 🐣").
   - **다운로드 버튼**(자리만) + "맥 먼저 · 윈도우 준비중" 보조문구.
   - 까딱이는 대표 펫 스프라이트.
2. **기능 카드 (3~4)**
   - 💊 복약·영양제·물 알림(복약지도·순응률)
   - 🌱 5단계 성장(잘 돌보면 가속)
   - 🧑‍🤝‍🧑 친구 초대·교배(합성·희귀종)
   - 🖥️ 바탕화면 위 귀여운 동반자(걷기·산책·감정)
3. **미리보기 · 성장**
   - 1→5단계 스프라이트 나열(성장 과정 시각화).
   - 알림 말풍선 목업("비타민D 챙길 시간! 💊 [먹었어요]") 1~2개.
4. **소개(스토리)**
   - "건강 습관을 게임처럼" — 잘 챙기면 자라고, 방치하면 시들고 끝내 떠나는
     다마고치형 동기 설계. 헬스케어 동반자 컨셉 한 문단.
5. **푸터 CTA**
   - 다운로드 버튼 재노출 + 제작자/포폴 링크 + 깃허브(선택).

## 7. 다운로드 버튼 동작 (1차)

- 실제 파일 링크 없음. 클릭 시 가벼운 안내(예: 토스트/말풍선 "곧 출시돼요 🥚")
  또는 "준비중" 상태 표시. 이후 .dmg 준비되면 `href`만 연결.
